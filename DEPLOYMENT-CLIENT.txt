CUM FUNCTIONEAZA (PENTRU CLIENT):
==================================

1. DESCARCA
   - Overview-App-Windows.zip (184 MB)

2. EXTRAGE
   - Clic dreapta pe ZIP → "Extract All"

3. CREARE SHORTCUT (O SINGURA DATA)
   - Deschide folderul extras
   - Dublu-click pe CREATE-SHORTCUT.bat
   - Vei vedea: "Shortcut created successfully"

4. FOLOSEAZA
   - Dublu-click pe icoana Overview de pe Desktop
   - Asteapta 5-10 secunde
   - APP-UL SE DESCHIDE AUTOMAT! 🎉
